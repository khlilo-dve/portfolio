Design Principles

三大核心工程设计

01 / STATE MACHINE

自然语言对话状态机

告别死记硬背的 CLI 参数。基于 Rust 内置 4 状态有限状态机，结合极简 LLM 意图解析器，能够理解口语化表达（如“整一篇”、“拉倒”、“把结尾改短”），抵御越界误操作。

02 / SKELETON & RENDER

骨架-渲染双通道 CoT

Pass 1 注入风格 Spec 生成逻辑骨架（把控信息密度与论证走向）；Pass 2 结合原始素材展开正文。彻底根治单次长文本生成的“逻辑坍缩”与空洞套话。

03 / DUAL DELIVERY

端到端双轨直达交付

从选题输入到双平台上线全程不切换工具。跨平台原生 CF_HTML 协议直达微信公众号剪贴板，Next.js MDX frontmatter 生成与 Git Push 直连云端部署。
