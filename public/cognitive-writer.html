Architecture

三大工业级设计，拒绝玩具范式

01 / DISPATCH

自然语言状态机

告别机械的 CLI 子命令。内置 4 状态有限状态机（Idle ↔ WaitingForOutline ↔ WaitingForFulltext ↔ WaitingForPublish），利用极简 LLM 意图分类器解析自然口语，精准匹配意图并抵御误操作。

02 / ENGINE

骨架-渲染双通道 CoT

Pass 1 提取并注入风格 Spec 输出结构化骨架（控制信息密度与逻辑走向）；Pass 2 结合素材展开高质量正文。彻底消除单次长文本生成的“逻辑坍缩”与空洞套话。

03 / PIPELINE

端到端双轨直达交付

从灵感输入到双端上线全程不切换工具。跨平台原生 CF_HTML 协议直达微信公众号剪贴板，Next.js MDX frontmatter 生成与 Git Push 直连云端部署。
